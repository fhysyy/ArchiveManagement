# 档案管理系统 —— 数据库设计（DDL v1.0 定稿）

> 数据库：SQL Server（与现有 CCV/FreeSql 栈一致；PostgreSQL 等价类型见注释）
> 约定：所有表含 `created_at`/`updated_at`；逻辑删除用 `status`/`is_deleted`；ID 用 `BIGINT IDENTITY`。
> 核心思路：**门类可配置 + 三级结构 + 自定义元数据存 JSON**，加新门类不改表结构。

---

## 0. 本版假设（如与实际不符请指出）
1. 单单位（单全宗），但保留 `fonds_id` 字段，后续可扩多全宗。
2. 门类：党政 / 科研 / 基建 / 文书 / 会计 / 声像 / 实物（前三个优先）。
3. 结构统一为 **门类 → 档案(案卷) → 文件(件) → 附件**；基建的"项目"用 `archive.parent_id` 自引用表达（项目=父档案，案卷=子档案）。
4. 自定义元数据（不同门类字段不同）存入 `dynamic_fields` JSON，不建宽表。
5. 用户规模数百人、内网/政务云、等保三级（设计上预留）。
6. 暂不对接触 OA、暂不做 SSO/CA，预留接口位。
7. 后端 .NET + FreeSql（复用现有栈）。

---

## 1. 实体关系（ER，文字版）

```
fonds(全宗) 1──* archive_category(门类) 1──* archive(档案)
sys_user *──* sys_role *──* sys_permission(角色×门类×操作×密级)
archive 1──* archive(自引用 parent_id，基建项目→案卷)
archive 1──* file_item(文件) 1──* attachment(附件)
sys_user 1──* borrow_request(借阅) ──> archive|file_item
audit_log(审计) 记录一切写操作
appraisal(鉴定) ──> archive|file_item
```

## 2. DDL

### 2.1 全宗 / 门类

```sql
CREATE TABLE fonds (
    id          BIGINT IDENTITY PRIMARY KEY,
    code        NVARCHAR(32) NOT NULL UNIQUE,   -- 全宗号
    name        NVARCHAR(128) NOT NULL,
    description NVARCHAR(512),
    status      TINYINT NOT NULL DEFAULT 1,      -- 1启用 0停用
    created_at  DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME(),
    updated_at  DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME()
);
-- PostgreSQL 等价: id BIGSERIAL PRIMARY KEY; 时间用 TIMESTAMPTZ DEFAULT now()

CREATE TABLE archive_category (
    id                  BIGINT IDENTITY PRIMARY KEY,
    fonds_id            BIGINT NOT NULL REFERENCES fonds(id),
    code                NVARCHAR(32) NOT NULL,            -- 门类代码: DZ(党政) KY(科研) JJ(基建) WS(文书) KJ(会计) SX(声像) SW(实物)
    name                NVARCHAR(64) NOT NULL,
    description         NVARCHAR(512),
    status              TINYINT NOT NULL DEFAULT 1,
    sort_order          INT NOT NULL DEFAULT 0,
    template_json       NVARCHAR(MAX) NOT NULL,          -- 元数据模板: [{key,label,type,required,enum,default}]
    fk_rule             NVARCHAR(256),                    -- 档号规则: {fonds}-{code}-{year}-{seq}
    default_retention   NVARCHAR(16) DEFAULT '30年',       -- 默认保管期限
    allowed_attach_types NVARCHAR(256) DEFAULT '.pdf,.doc,.docx,.jpg,.png,.mp3,.mp4',
    created_at          DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME(),
    updated_at          DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME(),
    CONSTRAINT uq_cat_code UNIQUE (fonds_id, code)
);
```

`template_json` 示例（科研门类）：
```json
[
  {"key":"project_no","label":"项目编号","type":"text","required":true},
  {"key":"project_name","label":"课题名称","type":"text","required":true},
  {"key":"leader","label":"负责人","type":"text","required":false},
  {"key":"result_type","label":"成果形式","type":"select","enum":["论文","专利","软件","报告"],"required":false}
]
```

### 2.2 核心三级：档案 → 文件 → 附件

```sql
CREATE TABLE archive (
    id              BIGINT IDENTITY PRIMARY KEY,
    fonds_id        BIGINT NOT NULL REFERENCES fonds(id),
    category_id     BIGINT NOT NULL REFERENCES archive_category(id),
    parent_id       BIGINT NULL REFERENCES archive(id),   -- 自引用: 基建项目(父)→案卷(子)
    is_project      BIT NOT NULL DEFAULT 0,                -- 1=基建项目节点(父) 0=普通案卷
    archive_no      NVARCHAR(64) NOT NULL,                -- 档号
    title           NVARCHAR(256) NOT NULL,
    year            INT,
    retention       NVARCHAR(16),                          -- 保管期限: 永久/30年/10年
    secrecy_level   NVARCHAR(16) DEFAULT '公开',           -- 公开/内部/秘密/机密/绝密
    org_unit        NVARCHAR(128),                         -- 编制单位/责任部门
    description     NVARCHAR(MAX),
    status          TINYINT NOT NULL DEFAULT 0,            -- 0草稿 1已归档 2已销毁 3退回
    dynamic_fields  NVARCHAR(MAX),                         -- 门类自定义元数据(JSON)
    creator_id      BIGINT,
    created_at      DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME(),
    updated_at      DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME(),
    CONSTRAINT uq_archive_no UNIQUE (fonds_id, archive_no)
);
CREATE INDEX ix_archive_cat ON archive(category_id);
CREATE INDEX ix_archive_parent ON archive(parent_id);
CREATE INDEX ix_archive_title ON archive(title);

CREATE TABLE file_item (
    id              BIGINT IDENTITY PRIMARY KEY,
    archive_id      BIGINT NOT NULL REFERENCES archive(id),
    title           NVARCHAR(256) NOT NULL,               -- 文件标题
    doc_date        DATE,                                  -- 成文日期
    author          NVARCHAR(128),                         -- 责任者
    pages           INT,
    seq_no          INT,                                   -- 卷内序号
    file_no         NVARCHAR(64),                          -- 文号(党政)
    project_no      NVARCHAR(64),                          -- 项目编号(科研/基建)
    dynamic_fields  NVARCHAR(MAX),
    created_at      DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME()
);
CREATE INDEX ix_file_archive ON file_item(archive_id);

CREATE TABLE attachment (
    id              BIGINT IDENTITY PRIMARY KEY,
    file_item_id    BIGINT NOT NULL REFERENCES file_item(id),
    file_name       NVARCHAR(256) NOT NULL,                -- 存储名(含路径/对象key)
    original_name   NVARCHAR(256),                         -- 原名
    mime_type       NVARCHAR(128),
    size_bytes      BIGINT,
    hash            NVARCHAR(64),                          -- SHA256 防篡改
    version         INT NOT NULL DEFAULT 1,
    ocr_text        NVARCHAR(MAX),                         -- OCR 全文(二期)
    watermark_flag  BIT NOT NULL DEFAULT 1,                -- 预览/下载加水印
    uploaded_by     BIGINT,
    uploaded_at     DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME()
);
CREATE INDEX ix_attach_file ON attachment(file_item_id);
```

### 2.3 权限（五维：角色 × 门类 × 操作 × 密级）

```sql
CREATE TABLE sys_user (
    id              BIGINT IDENTITY PRIMARY KEY,
    username        NVARCHAR(64) NOT NULL UNIQUE,
    name            NVARCHAR(64),
    dept            NVARCHAR(128),
    password_hash   NVARCHAR(128),
    status          TINYINT NOT NULL DEFAULT 1
);
CREATE TABLE sys_role (
    id              BIGINT IDENTITY PRIMARY KEY,
    code            NVARCHAR(32) NOT NULL UNIQUE,
    name            NVARCHAR(64) NOT NULL
);
CREATE TABLE sys_user_role (
    user_id         BIGINT NOT NULL REFERENCES sys_user(id),
    role_id         BIGINT NOT NULL REFERENCES sys_role(id),
    PRIMARY KEY (user_id, role_id)
);
CREATE TABLE sys_permission (
    id              BIGINT IDENTITY PRIMARY KEY,
    role_id         BIGINT NOT NULL REFERENCES sys_role(id),
    category_id     BIGINT NULL,                           -- NULL=全部门类
    op              NVARCHAR(16) NOT NULL,                 -- view/edit/audit/destroy
    max_secrecy     NVARCHAR(16) DEFAULT '公开'             -- 该角色可见最高密级
);
```

### 2.4 业务流：借阅 / 鉴定 / 审计

```sql
CREATE TABLE borrow_request (
    id              BIGINT IDENTITY PRIMARY KEY,
    applicant_id    BIGINT NOT NULL REFERENCES sys_user(id),
    target_type     NVARCHAR(16) NOT NULL,                 -- archive / file
    target_id       BIGINT NOT NULL,
    reason          NVARCHAR(512),
    status          NVARCHAR(16) NOT NULL DEFAULT 'pending', -- pending/approved/rejected/returned/expired
    approved_by     BIGINT,
    approved_at     DATETIME2,
    expire_at       DATETIME2,                             -- 利用期限
    created_at      DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME()
);
CREATE INDEX ix_borrow_applicant ON borrow_request(applicant_id, status);

CREATE TABLE appraisal (
    id              BIGINT IDENTITY PRIMARY KEY,
    target_type     NVARCHAR(16) NOT NULL,
    target_id       BIGINT NOT NULL,
    propose_reason  NVARCHAR(512),
    status          NVARCHAR(16) NOT NULL DEFAULT 'pending', -- pending/approved/destroyed/kept
    approved_by     BIGINT,
    executed_at     DATETIME2,
    created_at      DATETIME2 NOT NULL DEFAULT SYSUTCDATETETIME()
);

CREATE TABLE audit_log (
    id              BIGINT IDENTITY PRIMARY KEY,
    user_id         BIGINT,
    action          NVARCHAR(32),                          -- create/update/delete/audit/borrow/destroy
    target_type     NVARCHAR(32),
    target_id       BIGINT,
    detail          NVARCHAR(MAX),
    ip              NVARCHAR(64),
    ts              DATETIME2 NOT NULL DEFAULT SYSUTCDATETIME()
);
CREATE INDEX ix_audit_ts ON audit_log(ts);
```

## 3. 种子数据（门类模板，一期优先 3 类）

一期仅预置 **党政 / 科研 / 基建** 三类（`archive_category.template_json` 示例）：

**DZ 党政**
```json
[{"key":"file_no","label":"文号","type":"text"},
 {"key":"send_org","label":"发文机关","type":"text"},
 {"key":"main_send","label":"主送","type":"text"},
 {"key":"copy_send","label":"抄送","type":"text"}]
```
`fk_rule`: `{fonds}-DZ-{year}-{seq}`；`default_retention`: `30年`。

**KY 科研**
```json
[{"key":"project_no","label":"项目编号","type":"text","required":true},
 {"key":"project_name","label":"课题名称","type":"text","required":true},
 {"key":"leader","label":"负责人","type":"text"},
 {"key":"result_type","label":"成果形式","type":"select","enum":["论文","专利","软件","报告"]}]
```
`fk_rule`: `{fonds}-KY-{year}-{seq}`；`default_retention`: `30年`。

**JJ 基建**
```json
[{"key":"project","label":"工程项目","type":"text"},
 {"key":"building","label":"单体","type":"text"},
 {"key":"stage","label":"阶段","type":"select","enum":["前期","施工","竣工"]}]
```
`fk_rule`: `{fonds}-JJ-{year}-{seq}`；`default_retention`: `永久`。基建"项目"用 `is_project=1` 的 archive 行 + `parent_id` 挂接案卷。

> 其余门类（文书/会计/声像/实物）后续直接新增 `archive_category` 行即可，无需改表结构。

## 4. 索引与性能要点
- `archive(category_id, status)` 复合索引支撑按门类列表。
- `archive.title`、`file_item.title` 建全文索引或交 Elasticsearch。
- 附件实体走对象存储，DB 只存 `file_name`(对象 key) + 哈希。
- `dynamic_fields` 不索引（检索走固定字段 + 全文），如需按自定义字段检索，二类门类可建扩展表。
